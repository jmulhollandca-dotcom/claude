# Adopting the Staged Handoff Process on a New Project

1. **Get the permit first.** Pull the building permit and every partial or phased occupancy area on it with its occupancy date. That list is the handoff package list. No permit yet means no package dates yet. Enter the expected areas with Date confidence = No date yet.
2. **Copy `docs/specs/01 77 19 Staged Handoff.md` into the project specifications** under Division 01. Cross-reference from 01 77 00 Closeout Procedures and 01 91 13 General Commissioning. Fill in the bracketed project values.
3. **Build the package map.** Every room and every system assigned to exactly one occupancy package. Gaps listed, not blanked.
4. **Build the rows.** One Tasks row per room per stage H1, H2. One per system per stage H3, H4, H5. One per package for H6, plus one row per AHJ pre-occupancy inspection linked as a predecessor of it. One each for H0 and H7. Lay up the REF tables first.
5. **Set the gate-date columns on the room schedule board** to match the ladder. Enter each package's occupancy date against its rooms, permit as source.
6. **Name the roles** in section 7 of the process document.
7. **Issue the certificates** from `templates/handoff/` as the only accepted submission form. A handoff submitted without the certificate is returned unread.
8. **At each weekly review** read the release list and the holding list, and the days remaining to each package's occupancy date.
9. **At project close** harvest lessons against this process and raise a revision.

Per-project values to fill: project ID, permit numbers and occupancy areas with dates, room-to-package map, system list, review windows, role names, register board names and column labels.
